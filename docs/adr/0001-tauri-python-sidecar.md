# Ship a Tauri 2 desktop host with a Python sidecar

**Status: accepted.** The application uses the current stable Tauri 2 line as its desktop host, with a React 19, TypeScript 7 and Vite 8 renderer, while a frozen Python 3.13 sidecar remains the sole owner of workspace state, batch preparation, yt-dlp access and the local Automic Vault adapter. The Tauri host supervises that long-lived core and exposes a narrow typed command/event bridge over private structured IPC; it does not introduce a public loopback API. This preserves the working Python domain core and gives the product a durable desktop shell, explicit privilege boundary and signed-update path. pywebview was rejected because its in-process migration convenience would make the host/core boundary less durable; Electron was rejected because it adds Chromium and Node without removing Python. Tauri 3 is excluded until it is stable.
