# 视频基础信息交付记录

依据 [阅读资料库设计](workbench-library.md#视频基础信息) 实现频道、YouTube 发布时间与源视频时长的一致展示。日期使用平台发布时间，文稿预计阅读时长单独标注。范围包括发现结果接口、处理队列、当前处理视频、时间流、文档库、频道索引和详情面板。

时长复用已有 yt-dlp 元数据请求，不增加历史补齐任务。元数据取得后立即保存，字幕失败、重启和重新生成文稿均保留已知时长。未知、无效、直播中或尚未开播的时长不冒充已确定的视频长度。未执行任何数据清空。
