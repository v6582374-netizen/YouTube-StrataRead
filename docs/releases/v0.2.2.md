# Edison v0.2.2

- YouTube 的暂停／恢复、检查更新和批量重试收进页头，使用带完整提示的紧凑图标按钮，保留忙碌与冷却期间的禁用行为。
- 正式版与开发版分别使用独立状态目录，YouTube 资料库归属于各自的 Edison 状态目录，不再自动读取旧独立工具的数据。账号授权令牌按资料库隔离；OAuth 客户端配置优先使用当前资料库的配置，没有时检测并复用 Automic Vault 中已有的全局配置。
- 菜单栏与 Dock 统一使用已选定的 mymind thinker 母版，替换旧星形菜单栏图标。

## 数据边界变化

v0.2.1 会读取同机旧 YouTube 工具的资料库。本次通过原始发行 ZIP 解包后的后端和模拟旧记录复现；ZIP 文件清单检查没有发现个人状态数据库或凭据文件。这证明本机数据复用问题，不构成已经向其他用户泄露记录的证据。

macOS 正式版数据位于 `~/.config/edison`，开发版位于 `~/.config/edison-dev`；各自的 YouTube 数据位于 `youtube` 子目录。旧 `~/.config/coworker` 及 `~/Library/Application Support/youtube-reading-workbench/workspace` 保持原样，不自动复制、不删除。

升级到本版首次进入新资料库，需要配置模型并重新授权 YouTube 账号；Vault 中已有的 OAuth 客户端配置无需重复填写。之后重新启动或升级会保留该正式版资料库，不会每次清空。显式指定 `COWORKER_STATE_DIR` 仍可选择自定义状态目录；桌面宿主会固定向后端传递该目录及其中的 YouTube 资料库，避免 shell 配置把后端指向另一份数据。

## 发布检查

macOS 打包流程现在运行 `tests/smoke_desktop_privacy.py`：扫描 sidecar 是否混入常见用户状态文件，启动实际冻结后端，确认在同一隔离用户目录存在模拟旧订阅和视频时，新资料库仍为空，且旧记录不变。凭据隔离另有回归测试。

本地安装包仍面向 Apple Silicon、macOS 14 或更高版本，采用 ad-hoc 签名，未进行 Apple 公证。
